# Security

If you find a vulnerability in mlclean, please report it privately through
GitHub's security advisories ("Report a vulnerability" on the Security tab)
or by email to dhankechakrushil@gmail.com. Don't open a public issue for it.

You can expect an initial reply within a few days. Once a fix is released,
the advisory will be published with credit unless you prefer otherwise.

Only the latest release is supported with security fixes.
